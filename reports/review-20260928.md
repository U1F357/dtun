# 2026-09-28 实现检查与本地整理

本轮检查协议编解码、重组边界、软切换协程生命周期、TUN/UDP I/O、pacer、参数校验、部署脚本及现有测试。属于实现检查与定向修复，不是“已证明没有任何问题”，也不是完整安全审计或数日 soak。服务器在用服务未被本轮更新；远端仅运行独立候选程序与隔离命名空间测试。

## 已改进

1. 发送队列满时，旧实现仍复制完整 IP 包再尝试入队。改为单生产者检查容量，满时不分配/复制；保持全包 tail-drop 与 FIFO 语义，不声称解决流间公平性。单元测试验证拒绝分配为零、成功入队仍拥有独立副本。微基准见 `review-20260928/queue-benchmark.txt`；不把微基准当成公网吞吐提升。
2. TUN 采用 O_NONBLOCK/O_CLOEXEC，先 TUNSETIFF 再交给 Go netpoll。Run 在取消时关闭 TUN 并等待读取/日志协程退出，避免遗留阻塞 I/O。初次 Linux 验证发现过早注册 netpoll 导致不收包，调整顺序后重测；最终 Linux 实测验证标志确为非阻塞，Close 能中断 Read。
3. 新增八项有范围限制的 MTU/资源参数，默认保持不变；细节见 `../CONFIGURATION.md`。限制与协议边界相容，重组包数不超过固定 4096 ID 窗口；客户端排空时间不能超过切换周期。
4. UDP 缓冲设置失败不再静默忽略；服务端 allow-ip 必须是字面 IPv4，endpoint 解析及资源配置错误尽早暴露。socket 请求值仍可能被内核截断，未错误宣称它等于实际大小。
5. ICMP 丢包诊断避免将非首片 IPv4 fragment 的载荷误读为 ICMP echo 头。

## 保留的限制与后续优先级

- **按流公平排队/AQM**：这是下一项最有价值的排队改进，需针对 TCP/UDP/IPv4 fragments/IPv6 正确定义流键，并验证小流延迟、吞吐、公平性和内存上限。当前明确仍为共用 FIFO，不用“容量可调”冒充公平性修复。
- **自适应 pacer**：固定 80 Mbps 不跟随链路降速。需要接收反馈和速率算法的独立设计/对照，不能靠扩大队列解决。
- **同端口重连**：当前一个端口上的既有会话可能短暂阻挡新来源握手；多端口失败转移可恢复，但进程重启不是无缝切换。Pion listener/连接分发重构应单独验证身份认证、资源限制与关闭行为。
- **性能**：后续先用 CPU/alloc profile 决定是否优化逐片分配、指标锁和 socket 批处理。没有在缺乏 profile 时引入 buffer pool 或批处理，避免包生命周期/顺序回归。
- 降权、证书轮换仍按此前约定暂不做；DTLS 原生特征、有限排空窗口、无 ARQ/FEC 和不可保证 ISP 限速改善的边界不变。

## 验证

本地 race、vet、参数边界、队列所有权/零分配、取消时 TUN 关闭、非默认重组超时测试通过。真实 Linux 非阻塞 TUN/Close 测试在专用命名空间运行并通过，见 `review-20260928/linux-tun-test.txt`。

网络回归使用 queue=512、重组包数=128、预算=256 KiB、重组/排空=500ms、socket 请求=1 MiB、握手超时=2s；每 5 秒切换 80/443/23333。检查 MTU1500、IPv6 TUN、双向 TCP、UDP、ICMP、候选端口封锁与恢复、外层 1173 上限、清理退出。全部通过，原始记录在 `review-20260928-lab/`。另以 MTU9000 的 TUN 连接 MTU1500 的独立出口，IPv4 DF/非 DF、IPv6 PTB、缩小包与 TCP 测试通过，记录在 `review-20260928-mtu/`。

## 可调 MTU

新增 `--mtu 576..9000`，默认 1500。编解码/重组上限扩展至 9000，维持每片 1100 与 UDP cap1200；验证 9000 字节 IPv4/IPv6 包穿越 1500 外层链路。接收端拒绝超过本地 MTU 的声明并计数，要求两端配置一致；未实现自动协商。CLI 校验重组预算足以容纳一个所配置 MTU 的常规分片包。客户端测试 veth 从实际 TUN MTU 读取值，移除该处 1500 写死。

出口 MTU 的处理交给 Linux IPv4/IPv6 路由栈，真实验证 ICMP PMTU 通知而非只检查代码。未实现外层路径 MTU 探测；详见配置文档的内外层 MTU 区分。

MTU576 的 IPv4 TCP/UDP/ICMP 独立回归通过（该 MTU 不启用 IPv6），记录在 `review-20260928-mtu576/`；更新后的编解码 fuzz 10 秒通过。
